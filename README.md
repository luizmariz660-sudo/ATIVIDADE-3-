# ATIVIDADE 3

Projeto em Python com as atividades de cálculo de desconto e pesquisa de satisfação.

## Conteúdo
- `Untitled-1.py` — cálculo de desconto por faixa de valor
- `desconto_loja.py` — versão alternativa do mesmo cálculo
- `pesquisa_satisfacao_tudoweb.py` — pesquisa de satisfação com 50 entrevistados

## Como executar
```bash
python Untitled-1.py
python desconto_loja.py
python pesquisa_satisfacao_tudoweb.py
```
