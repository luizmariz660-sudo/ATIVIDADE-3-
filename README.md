# ATIVIDADE 3 - Pesquisa de Satisfação

Projeto em Python para registrar a opinião de 50 entrevistados sobre o atendimento de uma empresa.

## Conteúdo
- `pesquisa_satisfacao_tudoweb.py` — coleta as respostas e exibe o total de avaliações "EXCELENTE" e "RUIM"

## Como executar
```bash
python pesquisa_satisfacao_tudoweb.py
```
